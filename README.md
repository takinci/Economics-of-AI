# Who Pays for Radiology AI?

A world tour of 18 stops on how radiology AI is paid for, who pays, and who keeps the value it creates.

This is a long-form, interactive briefing: the bet, the evidence, a filterable world tour on a map, and what to do next. It is a single self-contained page ([index.html](index.html)) published with GitHub Pages.

## Author

Tugba Akinci D'Antonoli

## Running locally

No build step is needed. Open `index.html` in a browser. Web fonts load from Google Fonts, so an internet connection is needed for the intended typography.

## Deployment

The site is deployed with GitHub Pages through the workflow in [.github/workflows/jekyll-gh-pages.yml](.github/workflows/jekyll-gh-pages.yml).
